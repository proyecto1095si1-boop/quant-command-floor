# ADR 0018: evidencia positiva antes de promover consenso

- Estado: aceptada
- Fecha: 2026-10-21

## Decisión

Exigir un e-process de no inferioridad global y por régimen, muestra planificada,
guardrails operativos, ausencia de rollback y dos aprobadores para graduar un
experimento. Vincular el artefacto hasheado a la promoción posterior. Permitir
solo el bootstrap del primer champion sin comparador.

## Consecuencias

- “No hubo alarma” deja de ser evidencia suficiente.
- Un challenger puede permanecer indefinidamente sin graduar si el efecto es
  pequeño o los regímenes tienen poca muestra.
- Graduación y promoción son acciones separadas y auditables.
- Los defaults no son autorización para capital real.
